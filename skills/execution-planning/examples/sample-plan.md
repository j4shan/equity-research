## Execution Protocol

Dispatch wave by wave:

1. **Wave 1** — do `seed-graph` on the main thread; mark it `done`.
2. **Wave 2** — launch all four analyst subagents in a **single message with four `Task` calls**; wait for all to reach `done`/`failed`. Note any gap and proceed rather than blocking the whole report on one analyst.
3. **Wave 3** — perform `synthesis` on the main thread; write the draft `report.md`.
4. **Wave 4** — spawn `adversarial-reviewer`; resolve each challenge once (accept or rebut).
5. **Wave 5** — render visuals + HTML and commit the run folder.

Update each Objective Tracker row to `in_progress` when it starts and `done`/`failed` when it ends. Do not begin a wave until the prior wave's tasks are `done` or explicitly waived with a noted reason.
